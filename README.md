# 太阳观察台 · Sun Observatory

一个置身宇宙的交互式天文教学应用：理解北京的日出日落与季节变化，以及月球为什么发亮、月相如何变化。

技术栈：**Vite + 原生 JavaScript（ES Modules）+ Three.js**，无前端框架、无后端。

- [在线体验](https://happyphper.github.io/solar-observatory/)
- [项目源码](https://github.com/happyphper/solar-observatory)

第一次体验可以先打开右侧观察面板，聚焦地球并锁定北京，再播放一天或拖动时间；切换夏至、冬至，比较昼夜；最后打开月球面板观察月相。

## 快速开始

```bash
# 1. 安装依赖（Node 18+，建议 20/22）
npm install      # 或 npm ci（使用锁文件）

# 2. 启动开发服务器
npm run dev      # http://127.0.0.1:5173/

# 3. 生产构建与本地预览
npm run build    # 产物在 dist/
npm run preview  # http://127.0.0.1:4173/

# 4. 运行计算逻辑测试（Node 内置 test runner，26 个用例）
npm test
```

请通过 HTTP 地址打开，不要双击 `index.html`（ES Modules 与贴图路径需要 HTTP 环境）。

## 你可以做什么

- **全景视角**：太阳居中发光，地球带着大气与清晰的昼夜分界线，月球沿倾斜椭圆轨道运行；年轨道与月球轨道可见。
- **点击地球 → 地球近景**：金色晨昏线（太阳中心几何高度 0°）清楚地分开昼面与夜面；穿过南北两极的地轴与垂直地轴的赤道线在全部三种视角均可见，直观呈现 23.44° 倾角。
- **锁定北京**：镜头跟随太空中的北京，拖动时间即可看到晨昏线扫过北京——太阳没有“落下”，是北京随地球自转进入了夜晚。
- **点击月球 / 地月系统**：观察月球按日期运行、同步自转（始终以同一面朝向地球），金色箭头指向太阳，月球亮面始终朝向太阳。
- **调整日期（2024-01-01 ~ 2036-12-31）、北京时间与播放速度（0.1×/0.25×/0.5×/1×/2×/4×）**：
  - 播放一天：60 模拟分钟/秒，1× 约 24 秒，停在次日同一时刻；
  - 演示地球公转：12 模拟天/秒，仅全景可用，时钟保持选定的北京时间；
  - 演示月球公转：1.4 模拟天/秒，约 29.53 天（一个朔望月）后自动暂停，月相回到起始形状；播放期间相机始终跟随地球公转平移，地球保持居中，月球在画面中绕地运行。
- **月相面板**：给出“从地球看、北向上”的月相示意图、月相名称、受光比例、真实地月距离与北京月心高度。
- **首次加载欢迎页**：加载期间展示应用简介与三张主题示意图（日出日落 / 季节变化 / 月球与月相），背景为闪烁星空与日地月运转动画；欢迎页最少展示 2 秒（加载再快也等满），下方分阶段显示进度——初始化 3D 引擎（4–20%）→ 加载地球贴图（22–55%）→ 加载月球贴图（55–90%）→ 完成（100%）。贴图通过 fetch 流式读取，百分比对应真实字节数；后台标签导致 WebGL 未就绪时会显示重试次数。
- 桌面与手机均可用：响应式布局、触控支持、键盘可达、支持“减少动态效果”。
- **观察面板默认收纳**：右侧只保留一个很小的圆形入口（滑块图标），点击后面板从右侧滑出；面板左缘的 ✕（或 Esc）可将其收回，画面更沉浸。

## 科学原理与算法

| 主题 | 实现 |
| --- | --- |
| 时间模型 | 唯一物理状态为 UTC 毫秒瞬时；界面统一显示北京时间（UTC+8）。日期解析为严格正则 + 真实日历校验，不使用 `new Date(str)`，结果与运行环境时区无关。 |
| 太阳位置 / 日出日落 | NOAA 太阳算法（时差 E、赤纬 δ）；日出日落采用天顶角 **90.833°**（平均大气折射 34′ + 太阳视半径 16′）。画面金色晨昏线对应**太阳中心几何高度 0°**，与含视圆盘和折射的日出日落时刻是两种定义。 |
| 地球公转与季节 | 连续太阳黄经（USNO 近似）；地轴在空间中保持约 23.44° 固定倾角，季节由地表法线与阳光方向的夹角变化决定。 |
| 月球轨道 | Paul Schlyter 月球算法：倾斜椭圆轨道（半长轴 60.2666 地球半径、偏心率 0.0549、倾角 5.1454°），开普勒方程 Newton 迭代，含主要轨道摄动（黄经 12 项、黄纬 5 项、距离 2 项）。 |
| 月相 | phase = wrap(λ_月球 − λ_太阳)/2π；受光比例 ≈ (1 − cosβ·cos(λ_月−λ_日))/2。主相名称只在 ±2° 窄窗内使用。 |
| 同步自转 | 月球自转角速度与公转角速度一致（按平均黄经驱动），近似始终以同一面朝向地球。 |
| 北京月心高度 | 含地球扁率、观察者地表地心视差与真实天文距离（非场景压缩距离）的月心几何高度，输出高度角与方位角。 |

### 开发阶段的数据核对记录（2026-09-29）

以下为豆包开发交付时记录的抽样核对，公开发布时未重新执行这些外部天文数据校验。

- 日出日落对照 **USNO 官方 API**：2026-03-20 / 06-21 / 12-21 误差 ≤ 1 分钟（预算 3）；范围两端 2024-01-01、2036-12-31 误差 ≤ 2 分钟（预算 5）。
- 四个主月相（2026 年 9 月 USNO 数据）：相位环形误差 ≤ 0.0001 周（预算 0.002），受光比例误差 ≤ 0.0006（预算 0.01）。
- 2026-09-26 北京：USNO 月出/月落（上月面口径）时刻，本应用月心高度分别为 −0.87°/−0.92°，上中天地心高度 53.38°、方位 179.8（正南），距离约 38.0 万 km。

以上为抽样核对结果，不代表整个支持日期范围都达到同等精度；本应用是教学演示，不是天文观测预报。

### 刻意简化（请在教学中说明）

- **大小与距离为教学示意**：太阳、地球、月球的尺寸与距离经过压缩（地月距离、日地距离均不按真实比例），但面板显示的公里数来自真实轨道计算；月球半径约为地球的 0.272 倍。
- **未模拟日食与月食**：没有实现日月遮挡阴影的几何计算。
- **未完整模拟月球天平动**：同步自转仅为近似，月面朝向的小幅摆动未建模。
- 地球年轨道画为教学圆形；轨道相位由连续天文关系驱动，而非固定帧数。
- NASA 贴图是历史卫星合成图，不是实时云层或天气照片。
- 地球昼夜由平行光计算（真实阳光为平行光），明暗分界平面过地心，与金色晨昏线环严格重合；月球因场景距离压缩，用位于太阳的点光源照亮、亮面朝向画面中可见的太阳（与地球通过 layers 分别打光）。夜面保留低强度环境光以辨认地表纹理，并非纯黑。
